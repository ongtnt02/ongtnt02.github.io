# assets/ — 이미지 자리

이 폴더는 **비어 있습니다.** 지금 페이지는 사진 없이 CSS·타이포그래피·도형으로만 만들어졌습니다.

## 왜 비워 두었나

타사 보도·분양 홍보물의 조감도·투시도·평면도는 저작권 문제가 있어 내려받아 쓰지 않았습니다.
사용자가 직접 촬영했거나 사용 권한을 가진 자료만 이 폴더에 넣고 연결해 주세요.

## 파일을 넣을 자리 (index.html의 주석 표시)

| 자리 | 파일 이름 제안 | 권장 크기 | 내용 |
|---|---|---|---|
| 히어로 배경 (선택) | `hero.jpg` | 1600×900 | 단지 조감·현장 전경. 넣지 않으면 지금의 능선 그래픽이 그대로 보입니다 |
| 위치 지도 | `map.png` | 800×1000 | 카카오맵·네이버 지도 캡처 또는 약도 |
| 평면도 1 | `plan-59.png` | 1200×900 | 전용 59㎡ 평면도 |
| 평면도 2 | `plan-84.png` | 1200×900 | 전용 84㎡ 평면도 |
| 현장 사진 (선택) | `site-01.jpg` | 1200×800 | 홍보관·현장 사진 |

## 넣는 방법

1. 위 이름으로 파일을 이 폴더에 저장합니다.
2. `index.html`에서 해당 자리의 주석(`<!-- 이미지 자리: ... -->`)을 찾아 아래처럼 바꿉니다.

   ```html
   <div class="plan-box" aria-hidden="true"><span class="plan-glyph"></span></div>
   ```
   →
   ```html
   <img src="assets/plan-59.png" alt="전용 59㎡ 평면도" width="1200" height="900" loading="lazy" decoding="async">
   ```

3. 사진에는 반드시 `alt`(대체 텍스트)를 넣고, 조감도·연출 이미지에는
   "이미지는 소비자의 이해를 돕기 위한 것으로 실제와 다를 수 있습니다" 안내를 함께 표시합니다.

## 지켜야 할 것

- 분양 홍보물·보도 사진을 출처 표시만 하고 쓰는 것은 사용 권한이 되지 않습니다.
- 지도는 카카오맵·네이버 지도 **공식 삽입(iframe) 코드**를 쓰면 저작권 문제가 없습니다.
- 이미지 용량은 한 장에 300KB 이내로 줄여 주세요(모바일 속도).
